# wa

Use `wa` when you want your personal WhatsApp in a terminal, a script or an agent: read chats, search them offline
and send messages. It links to your account as a device, the way WhatsApp Web does.

`wa` cannot link to WhatsApp yet; this release is the foundation. The [roadmap](roadmap.md) says what comes next.
